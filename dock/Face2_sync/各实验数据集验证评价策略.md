# 各实验数据集验证评价策略

## 1. 适用范围

本文档记录当前 R3DPR 二分类实验中 `nested-direct` 管线的统一训练、模型选择、外层测试和评价规范。该管线用于 Control/Patient 二分类任务，并适用于以下输入类型：

| 输入类型 | 典型输入目录 | 输入尺寸 |
|---|---|---:|
| Whole-face，R3DPR/SH093 | `data/processed/global_face_R3DPR/SH093/images` | 320 x 256 |
| Whole-face，R3DPR v2 | `data/processed/global_face_R3DPR_v2/relight_neutral_front/images` | 320 x 256 |
| Whole-face，未进行 R3DPR 处理 | `data/processed/global_face/realface_256x320_blackbg_from_raw_v1/images` | 320 x 256 |
| ROI，R3DPR 或人工偏移处理 | 对应 `eye_roi`、`cheek_roi`、`lip_roi` 目录 | 224 x 224 |
| ROI，未进行 R3DPR 处理 | `data/processed/roi_raw_dataset/manual_shift_data` 下的 ROI 目录 | 224 x 224 |
| ROI，其他 eye2 数据 | `data/processed/roi_dataset/other_roi/eye2_roi` | 224 x 224 |

除输入目录和图像尺寸外，各个模型实验均使用独立配置文件和独立输出目录。ResNet 主干可以切换为 ResNet18、ResNet34 或 ResNet50。

## 2. 任务定义与数据表

- 任务为直接二分类 `Control vs Patient`，不经过三分类标签映射。
- 类别编码固定为：`0 = Control`，`1 = Patient`。
- 模型输出为两个 logit，顺序为 `[Control, Patient]`。
- 图像文件通过 `{ID}.png` 规则从输入目录读取。
- 五折表格至少包含 `ID`、`patient_group_id`、`fold`、`binary_label` 和 `SEX` 五列。
- `ID` 在当前实验中必须唯一；每个图像必须存在，且图像源尺寸必须与配置一致。
- 外层折编号固定为 `0, 1, 2, 3, 4`，每折必须同时包含两个类别。

### 关于 group 的处理

按照当前实验约定，500 例被当作 500 个唯一 ID，`patient_group_id` 不参与外层折划分，也不参与内部训练/验证划分。该字段仍会被读取并写入 split manifest 和预测文件，用于追溯，但 `nested_direct.use_group_constraint` 固定为 `false`。

因此，当前结果回答的是“按 ID 独立划分时模型的二分类表现”。如果同一患者组中存在相关样本，忽略 group 约束可能使不同样本进入不同折，结果的外推性需要在论文中按这一实际设计进行表述，不能将其解释为严格的患者级独立验证。

## 3. Nested-direct 数据划分

当前协议名称为：`outer_5fold_inner_holdout_direct_test`。

对于外层第 `k` 折，执行以下步骤：

1. 将五折表中 `fold != k` 的 400 例作为 development set。
2. 将 `fold == k` 的 100 例固定为 outer held-out test set。该集合在模型选择完成前不被读取用于评价或选择。
3. 在 400 例 development set 内使用一次 `StratifiedShuffleSplit`，按 `binary_label x SEX` 分层，划分出 320 例 inner training set 和 80 例 inner validation set。
4. 仅使用 inner training set 进行训练；使用 inner validation set 监控训练过程、执行早停和选择最佳 checkpoint。
5. 恢复 inner validation Macro-AUC 最佳 checkpoint，直接对该折此前未参与模型选择的 100 例 outer test set 进行预测。
6. 不执行第二阶段的 400 例 refit；也就是说，inner 阶段确定的模型直接用于对应 outer fold 测试，这正是 `nested-direct` 名称中的 direct 含义。

五折完成后，每个 ID 恰好作为一次 outer test 样本，五个 outer test 集合合并形成 500 例 pooled OOF prediction。由于 outer test 在各折中均未参与模型选择，pooled OOF 结果用于主要性能报告。

## 4. 图像预处理与数据增强

训练和评价使用的变换由 `datasets/R3DPR/binary_face_dataset.py` 统一构建：

### Inner training set

1. Resize 到配置中的目标尺寸；
2. 训练阶段启用 `RandomHorizontalFlip`；
3. 转换为 Tensor；
4. 使用 ImageNet 归一化：
   - mean = `[0.485, 0.456, 0.406]`
   - std = `[0.229, 0.224, 0.225]`

训练时的模型参数更新使用带水平翻转的数据。为了记录可比较的 training loss 和 training metrics，inner training set 还会使用不带随机翻转的 evaluation transform 进行评估。

### Inner validation set 与 outer test set

两者均只使用确定性变换：Resize、ToTensor 和 ImageNet Normalize，不使用水平翻转或其他随机增强。当前 nested-direct 配置没有加入亮度、对比度、颜色抖动或随机裁剪等额外增强。

## 5. 模型初始化与训练配置

### 模型

- 主干：`resnet18`、`resnet34` 或 `resnet50`；
- 初始化：Torchvision ImageNet 预训练参数；
- 训练策略：`full_finetune`，即 backbone 和二分类 fc 层全部参与反向传播；
- 分类层：将原始 ResNet 全连接层替换为输出维度为 2 的线性层；
- 当前主实验通常不使用额外 Dropout，除非某个独立配置明确指定。

### 优化器与损失

| 项目 | 当前配置 |
|---|---|
| Optimizer | AdamW |
| Learning rate | `1e-4` |
| Weight decay | `1e-4` |
| Batch size | 16 |
| Maximum epochs | 50 |
| Loss | weighted cross-entropy with label smoothing |
| Label smoothing | `alpha = 0.05` |
| BatchNorm | 默认 train mode；全量微调时随模型训练 |
| Learning-rate scheduler | 当前 nested-direct 主配置不启用，等价于无 scheduler |

类别权重在每个 outer fold 的 inner training set 内单独计算：

\[
w_c = \frac{N_{train}}{2 n_c},
\]

其中 `N_train` 是该折 inner training set 的样本数，`n_c` 是类别 `c` 的样本数。这样每折的权重只由实际用于参数更新的训练样本决定，不使用 inner validation 或 outer test 的标签分布。

标签平滑使用 exclude-true-class 形式。对于二分类标签 `y`，目标分布为：

\[
q_y = 1-\alpha, \qquad q_{1-y} = \alpha.
\]

当前 `alpha=0.05`，同时保留每个类别的 fold-specific class weight。

### 随机性与运行环境

- 配置基础随机种子为 `2026`；
- 每个 outer fold 使用独立的模型初始化种子 `2026 + 10000 + fold`；
- DataLoader 当前使用 `num_workers=0`，并启用 `pin_memory=true`；
- 训练脚本要求使用 CUDA，当前管线不启用 CPU fallback；
- 输出目录会保存 Python、PyTorch、Torchvision、CUDA、GPU 和 git revision 等环境信息。

## 6. Inner validation 模型选择

每个 epoch 结束后执行以下评估：

- inner training set：使用无随机增强的 evaluation transform，记录 training loss 和 training metrics；
- inner validation set：使用确定性 evaluation transform，记录 validation loss 和 validation metrics。

模型选择指标固定为 inner validation Macro-AUC：

- 若当前 epoch 的 inner validation Macro-AUC 严格高于历史最佳值，则覆盖保存 `checkpoints/inner_best_macro_auc.pth`；
- 保存的 checkpoint 同时记录 epoch、inner best Macro-AUC、配置和训练信息；
- 连续 `10` 个 epoch 未改善时触发 early stopping；
- 最多训练 `50` 个 epoch，但由于 early stopping，实际运行 epoch 数可以少于 50；
- `selected_epoch` 是该 outer fold 最终使用的内部最佳 epoch。

这里的 early stopping 只依据 inner validation set，绝不依据 outer test set 的结果。outer test 只在 checkpoint 确定后执行一次预测。

## 7. Outer test 与 OOF 预测

对每个 outer fold，使用恢复后的 inner-best checkpoint 计算：

- `logit_control`、`logit_patient`；
- `prob_control`、`prob_patient`；
- `pred_class`；
- 样本 ID、原始 fold、标签、图像路径、selected epoch 和 checkpoint 路径。

二分类概率由 softmax 得到。当前没有进行阈值搜索、阈值校准或基于 outer test 的后处理。硬分类结果为：

\[
\hat{y}=\arg\max_c p_c,
\]

在二分类中等价于以 `prob_patient = 0.5` 作为 Patient 判定阈值。

## 8. 统一评价指标

五折合并后的 500 例 pooled OOF prediction 是主要结果来源。评价程序从原始 OOF probability 重新计算指标，不通过四舍五入后的折指标反推混淆矩阵。

### 8.1 Macro-AUC

使用每名样本的 `prob_patient` 和真实二分类标签计算 ROC-AUC：

\[
\mathrm{Macro\text{-}AUC} = \mathrm{ROC\text{-}AUC}(y, p_{patient}).
\]

在当前二分类实现中，名称沿用统一指标规范，实际计算的是 Patient 阳性概率对应的二分类 ROC-AUC。

### 8.2 混淆矩阵

固定矩阵标签顺序为 `[0, 1] = [Control, Patient]`：

\[
C =
\begin{bmatrix}
TN & FP\\
FN & TP
\end{bmatrix}.
\]

论文图中可以将显示名称写为 `Normal/Abnormal`，但必须保持类别编码、矩阵顺序和指标定义不变。

### 8.3 Macro-F1

分别计算两个类别的 F1，再取算术平均：

\[
\mathrm{Macro\text{-}F1} = \frac{F1_{Control}+F1_{Patient}}{2}.
\]

该指标使用 argmax 得到的硬分类结果。

### 8.4 Balanced Accuracy

二分类时为两个类别召回率的平均：

\[
\mathrm{Balanced\ Accuracy}
= \frac{\mathrm{Sensitivity}+\mathrm{Specificity}}{2}.
\]

### 8.5 Sensitivity 与 Specificity

以 Patient 为阳性类：

\[
\mathrm{Sensitivity} = \frac{TP}{TP+FN},
\qquad
\mathrm{Specificity} = \frac{TN}{TN+FP}.
\]

其中 Sensitivity 表示 Patient 识别能力，Specificity 表示 Control 识别能力。

## 9. 主要结果与稳定性结果

### 主要结果

主要结果统一报告 pooled OOF 的五个指标：

- Macro-AUC
- Macro-F1
- Balanced Accuracy
- Sensitivity
- Specificity

pooled OOF 混淆矩阵直接由 500 例 OOF hard predictions 汇总得到。

### 折间稳定性

每个 outer fold 单独计算同样的五个指标，并可报告五折 mean ± SD。该统计量只描述模型在不同 outer fold 上的稳定性，不替代 pooled OOF 主要结果，也不从中选择“最好的一折”作为总体结果。

对于训练过程诊断，可以使用每折 `inner_selection_history.csv` 绘制 training/validation loss 和 training/validation AUC；这类曲线用于识别过拟合和训练不稳定，不参与 outer test 结果选择。

## 10. 结果文件结构

### 训练阶段

实验输出目录通常包含：

```text
experiment_dir/
  config_snapshot.yaml
  environment.json
  data_audit_report.md
  fold_data_distribution.csv
  fold_0/
    inner_split.csv
    inner_selection_history.csv
    selected_epoch.json
    fold_protocol.json
    metrics.csv
    outer_test_confusion_matrix.csv
    outer_test_predictions.csv
    checkpoints/inner_best_macro_auc.pth
  ...
  fold_4/
```

### 汇总阶段

完成五折训练后，汇总程序生成：

```text
experiment_dir/
  oof_predictions.csv
  fold_metrics.csv
  oof_metrics.csv
  oof_confusion_matrix.csv
  binary_experiment_results.md
```

其中：

- `oof_predictions.csv` 保存每个 ID 唯一一次的 outer-held-out prediction；
- `fold_metrics.csv` 保存每折 outer test 指标和 selected epoch；
- `oof_metrics.csv` 保存 pooled OOF 五个主指标；
- `oof_confusion_matrix.csv` 保存 pooled OOF 混淆矩阵；
- `binary_experiment_results.md` 同时记录协议、pooled OOF 结果和折指标。

## 11. 一键运行入口

通用 nested-direct 入口为：

```text
scripts/run/R3DPR/nested-direct/run_r3dpr_resnet_binary_nested_direct_5fold.py
```

典型命令为：

```powershell
conda run -n face2 python scripts/run/R3DPR/nested-direct/run_r3dpr_resnet_binary_nested_direct_5fold.py `
  --config config/train/R3DPR/nested-direct/<experiment>.yaml
```

该入口依次调用训练、OOF 汇总和诊断绘图程序。训练脚本、评价脚本和配置快照共同构成一个实验的可复现记录。

## 12. 方法学边界

当前 nested-direct 已将模型选择和最终性能评价分开：outer held-out test 不参与训练、早停或 epoch 选择，因而比“同一 held-out 集同时用于验证和测试”的做法更严格，也不再直接产生那种测试集参与选择导致的明显乐观偏倚。

但当前实验明确忽略 `patient_group_id`，只按唯一 ID 处理 500 例数据。因此该管线不能宣称已经完成患者级 group-independent validation。若研究目标是评估对未见患者的泛化能力，后续需要单独建立 group-aware nested 管线，并将其结果与当前 ID-level nested-direct 结果区分报告。
