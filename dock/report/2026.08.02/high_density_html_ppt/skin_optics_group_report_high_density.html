01 · Research Framing
研究问题、术语边界与判定目标

研究问题

what to prove

基于皮肤光学前向模型合成监督所学习的 melanin-sensitive 与 hemoglobin-sensitive 分布图，能否在真实普通手机人脸图像中形成稳定表征，并为心功能状态二分类提供 RGB 之外的增量信息？

研究对象普通手机人脸图像，不是标准化光谱/色卡环境。
主判定RGB+M+H 是否相对 RGB 有稳定增量。
负结论允许成为正式结论，不通过堆模型复杂度掩盖失败。

术语边界

what not to claim
变量允许表述禁止解释
Mmelanin-sensitive representation真实黑色素浓度
Hhemoglobin-sensitive representation真实血红蛋白浓度 / 血氧
Sshading-related component定量光照或真实法线
Pspecular-related component定量表面反射生理量

没有标准色卡同步采集、皮肤光谱仪、组织学真值或已知手机 ISP，因此 M/H 只能作为光学约束的敏感表征。

六模块与两级评价阶段
A · SO-0冻结皮肤光学前向模型；M/H/S/P + 相机/光源/曝光 → sRGB patch。
B · Synthetic随机参数和空间场生成器；产出 RGB patch 与 M/H/S/P 真值。
C · SO-1U-Net 学习 linear-RGB → M/H/S/P 的逆向分解。
D · Real prep真实人脸对齐、全脸皮肤 mask、统一颜色入口。
E · Patch256 patch 切分、SO-1 推理、重叠区域加权合并。
F · ClassifierRGB / M+H / RGB+M+H / probes 的 ResNet18 二分类。
M

melanin-sensitive

黑色素吸收方向变化；主医学敏感表征之一。

H

hemoglobin-sensitive

血红蛋白吸收方向变化；二分类增量关注重点。

S

shading-related

吸收明暗、方向性光照和部分曝光影响。

P

specular-related

吸收高光和表面直接反射，防止污染 M/H。

05 · SO-1 / Real-Face Inference
分解网络、真实图接口与 patch 合并

SO-1 目标

decomposition
linear-RGB skin patch → M-sensitive → H-sensitive → S-related → P-related
  • 输入：3 × 256 × 256 linear-RGB。
  • 输出：4 × 256 × 256，channel = M/H/S/P。
  • 网络：标准容量 U-Net，64→128→256→512→1024。
  • 初始化：随机初始化，不使用 Carvana 预训练。

训练损失 / 配置

minimal protocol
L_total = (L_M + L_H + L_S + L_P) / 4 checkpoint = argmin(val_M_MAE + val_H_MAE) optimizer = AdamW lr = 1e-3, wd = 1e-4 epochs = 25, patience = 5 seed = 20260801

RGB 重建仅作离线物理一致性审计，不作为 v1 训练损失。

真实人脸推理

single interface
颜色入口RGB → sRGB [0,1] → inverse sRGB → linear-RGB
mask全脸有效皮肤；排除头发、眼球、鼻孔、嘴唇等
patch256×256；overlap=15；stride=241；skin ≥ 0.20
合并重叠区域线性渐变 / 平滑窗加权
输出M/H/S/P_full.npy + preview PNG + QC 图
Real images use the same color transform function for every case06 / 09

错误结构

sensitivity vs specificity

Sensitivity 高于 Specificity，提示 Patient 识别更充分，Control 侧仍需通过阈值、校准或样本结构进一步审计。

解释要求

increment claim

该结果需放入 RGB、M+H、RGB+M+H、S+P、Mask-only 的同折对照中解释，不能只凭单表宣称光学增量。
