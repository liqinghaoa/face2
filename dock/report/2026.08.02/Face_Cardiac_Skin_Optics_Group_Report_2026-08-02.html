基于皮肤光学敏感表征的人脸心功能二分类

从冻结的 SO-0 皮肤光学前向模型出发，用合成监督学习 M/H/S/P 分解表征，再迁移到真实手机人脸图像，评估其对 Control 与 Patient 二分类的增量价值。

SO-0 已冻结 SO-1 合成预训练 真实人脸 Patch 推理 RGB+M+H 分类
Research Question

研究核心是验证一条“物理约束表征能否提供分类增量”的闭环。

不是测量真实黑色素、血红蛋白浓度，也不是把 M/H 直接解释为血氧、灌注或临床诊断量。

汇报主线

科学定位普通手机人脸图像的 skin-optics-informed representation。
核心表征M: melanin-sensitive；H: hemoglobin-sensitive。
辅助分量S/P 承接阴影、高光和采集条件，防止污染 M/H。
验证问题M/H 能否为 Control vs Patient 二分类提供 RGB 之外的信息。

SO-0 / SO-1 Design

物理前向、合成数据和分解网络作为一个训练单元

SO-0 已冻结

SO0_Forward_Model_v1.1；109 个合格 camera-light 组合；M/H 在测试合成观测空间中未发生秩退化。

skin reflectance → camera RGB → white balance → XYZ / D65 → sRGB clipped

合成监督规模

Train20,000
Validation2,000
ID / OOD Test5,000
总计27,000

10,000 组基础 M/H 空间场 × 2 种采集条件。

SO-1 训练协议

标准容量 U-Net：3×256×256 linear-RGB 输入，输出 M/H/S/P 四通道。

L_total = (L_M + L_H + L_S + L_P) / 4 checkpoint = min(val_M_MAE + val_H_MAE)

RGB 重建仅用于离线审计，不作为训练损失。

Real Data + Classification

真实推理和分类矩阵放在同一套接口里控制

真实人脸推理接口

RGB image → assumed / encoded sRGB → float32 [0,1] → inverse sRGB → linear-RGB → SO-1
mask覆盖有效皮肤，排除背景、头发、眼球、鼻孔、嘴唇、牙齿等。
patch256×256，overlap=15，stride=241，valid skin ≥ 0.20。
合并重叠区域加权合并，保存高分辨率 M/H/S/P 浮点图。

结果读数

Macro-AUC 接近 0.86，说明当前二分类已经形成较强区分能力。Sensitivity 高于 Specificity，提示 Patient 识别相对更充分，Control 侧仍需校准。

后续比较重点

需要把该结果放回 RGB、M+H、RGB+M+H、S+P 和 Mask-only 的同折对照中，判断增量是否来自 M/H，而不是 mask、姿态、光照或相机条件。

Control Rules + Next Step

结论可信度取决于泄漏控制、停机规则和产物追踪

泄漏控制

SO-1 合成预训练不使用 NYHA 标签；冻结 SO-1 可对 500 例全量推理；继续使用 patient-group 固定五折，同一患者不同 visit 同折。

进入五折门槛

RGB+M+H 相对 RGB 的 Macro-AUC 提升约 ≥ 0.01；Macro-F1 或 BA 至少一项提升约 ≥ 0.01；M+H 的 Macro-AUC > 0.60；S+P 不得明显高于 M+H。

下一步产物

冻结配置、camera-light split、SO-1 checkpoint、全量 M/H/S/P 浮点图、QC 预览、224 分类资产、OOF 预测和 fold 级指标。

  • 若 M/H 在合成数据上无法恢复，或真实 M/H 大量坍塌、饱和、全零，应停止或降级路线。
  • 若必须修改 SO-0、删除难例、重分折或选择性报告才能提升，结果不应被接受。
